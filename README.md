# Trabalho Individual de Front-End

## Descrição
Este projeto é uma aplicação de front-end desenvolvida como parte de um trabalho individual. O objetivo é demonstrar habilidades em HTML, CSS e JavaScript.

## Estrutura do Projeto
- `index.html`: Página principal do projeto.
- `styles.css`: Arquivo de estilos CSS.
- `script.js`: Arquivo de scripts JavaScript.

## Funcionalidades
- [ ] Estrutura básica em HTML.
- [ ] Estilização com CSS.
- [ ] Interatividade com JavaScript.

## Como Executar
1. Clone o repositório:
    ```bash
    git clone https://github.com/cintra444/pagina_Elibra.git
    ```
2. Navegue até o diretório do projeto:
    ```bash
    cd front_end/trabalho_individual
    ```
3. Abra o arquivo `index.html` em seu navegador.
